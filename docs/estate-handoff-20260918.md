## 이번에 진행한 다음 단계

인계에 남은 무작위 대조군과 동일 조건 비교를 구현했다. 무작위 한 채 보유는 당시 적격·예산 내 후보에서 사전 고정 seed로 결정하며, 미래 가격이나 모델 점수를 추첨에 사용하지 않는다. 매수 뒤에는 정해진 출구까지 보유한다.

비교기는 보유·갈아타기·최저가·현금과 등록된 모든 무작위 결과를 요구한다. 입력 및 엔진 해시, 예산, 비용 값 전체, 판단/평가일, 체결·잔금 지연이 다른 결과를 섞지 못하게 한다. 체크포인트·정책 해시와 현금 대비 수익률도 대조한다. 원천자료의 사실성이나 실제 사전 등록 여부를 이 검사만으로 증명하지 않는다.

실패·미완료·미청산을 분모에 남기며, 미정산 seed가 있으면 무작위 중앙값과 그 대비 차이를 내지 않는다. 매수 미체결은 0% 현금 결과로 유지하되 매수하지 못했다는 표시를 남긴다. 무작위 반복은 동일 시장 경로를 공유하므로 독립 검증 기간 수로 세지 않는다.

대표 보고에는 이번 준비 범위와 날짜를 표시했다. 합성자료의 가상 수익 숫자를 공개 모델 성과로 게시하지 않는다. 운영 모델·순위·원본 자료·일일/월간 일정과 실자료 저장 게이트는 그대로다.

## 검증 범위

시뮬레이션·저장·비교 관련 41개 검사와 기존 UI 검사를 통과했다. 미래/과예산 후보 제외, 행 순서와 점수에 독립적인 추첨, 같은 seed 재개, 비용·시간 불일치, 누락/중복 seed, 미청산·부분 완료·미체결 처리, 실제자료의 저장 검증 요구를 확인했다. CLI의 가상 7개 시나리오도 정상 비교했다.

실제 역사 실험 0회, 실제 DB 조회·쓰기 0회, 새 임장 사실 0건, 모델 재학습 0회다. 과거 성과 개선이나 투자 결과를 얻었다고 해석하지 않는다. 이번 코드는 엔진 해시가 달라지므로 옛 체크포인트를 수정해 재개하지 않는다.
