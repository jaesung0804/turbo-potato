## 이번 변경

1. 잠재력 비교에서 모델·소외·저가·추세 방법이 **모두 존재하는 동일 시점**만 비교한다. 기존 `all(...)` 방식은 누락된 비교방법을 검사하지 못할 수 있었다. 중복 시점/방법, 잘못된 관측 건수도 차단한다.
2. 표시된 관측률을 그대로 믿지 않고 관측/선정 건수에서 재계산한다. 50%·20개 단지 조건을 유지하고, 제외 사유와 미관측 건수를 남긴다. 기존 결과의 순위·예측값과 모델은 바꾸지 않는다.
3. 기존 보고서만 읽는 작은 공개 검증 요약을 생성한다. 원본 보고서의 SHA-256, 기준일, 동일 시점 비교, 시점별 차이를 보존한다. 재학습·수집·DB 쓰기는 실행하지 않는다.
4. 대시보드에 거래자료 기준일·마지막 수집·화면 생성·수집 시도 상태를 나눠 표시한다. 인증 누락 시 기존 자료를 유지하면서 보류 상태를 표시한다. UI 전용 배포는 과거 수집 상태와 데이터 지문을 유지한다.
5. 대표 보고에 모델 비교, 대표 판단, 마지막 팀 보고, 다음 작업을 구분한다. 팀 보고의 9월 11일 기준과 이번 점검의 9월 15일을 혼동하지 않는다. 개인 주거·근무지 정보는 추가하지 않는다.

경기·인천 확장 진단의 모델 평가 29개 시점 중 네 방법 모두 같은 관측 조건을 만족한 시점은 17개다. 방식별 시점 중앙값은 잠재력 모델 +0.8236%, 소외 규칙 +1.3187%로 기존 보고서와 일치한다.

모델이 소외 규칙보다 나은 시점은 7/17개, **시점별 차이의 중앙값**은 -0.7424%p다. 이는 두 방식의 전체 중앙값을 단순히 뺀 값과 다른 통계량이다. 결과는 지역·면적 비교군 대비 변화이며 거래비용을 차감한 실제 투자수익률이 아니다. 평가 기간이 겹치고 과거 주소·단지 연결 검수가 남아 있어 독립 시행의 승률이나 정식 지역 확대 근거로 사용하지 않는다.

## 검증과 다음 실행

변경 관련 Python 검사 25개, 기존 UI 3종과 신규 대표 보고 UI 검사를 통과했다. 현재 공개 자료를 압축 약 22 MiB 범위에서 읽고 지문을 확인해 재사용한 UI 전용 후보에 대해 전체 기간·후보·신뢰도 연결 검사를 통과했다. 브라우저의 로컬 접근이 차단돼 실제 PC·모바일 시각 검증은 미완료다.

코드 변경은 별도 PR로 검증한다. 기존 일일/월간 일정과 수동 배포 경로를 유지하며 코드 push로 수집·학습·배포를 시작하지 않는다. 이번 연결에는 새 workflow dispatch 기능이 없어 수동 즉시 배포는 수행하지 못한다. 병합 후 기존 예약 배포 또는 권한 있는 환경의 `ui_only=true`, `refresh=false` 실행으로 반영한다. 실제 공개 SHA 확인 전에는 홈페이지 반영 완료라고 표시하지 않는다.

다음 우선순위는 비공개 수집 인증 복구 → 임장 인계 기록 대조 → 무료 용량과 복원 검증 → 사전 등록된 작은 패널에서 새로운 피처와 예산·비용 전략 비교다. 범용 모델에는 개인 주거 선호와 당시 존재하지 않았던 관측을 넣지 않는다.
