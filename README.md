# Official capital area apartment CSV research data

Public MOLIT CSV downloads, preserved separately from production inputs.
Use collection/manifest.json to distinguish completed, missing and unsupported coverage.
A successful state commit can contain an incomplete collection checkpoint.
Raw rows retain cancellations and identical-row multiplicity.
Historical downloads are current revised data, not historical publication vintages.
Sales begin in 2006; rental data begin in 2011; September 2026 is partial.
Each commit preserves the exact raw payloads referenced by its manifests.
