# 임장 비교표 자동 채우기

1. 대시보드에서 원하는 조건을 고른 뒤 **임장 비교표 Excel**을 받습니다.
2. **자동 채우기 받기** 압축파일을 별도 폴더에 풉니다.
3. `fill.cmd`를 실행하고 비교표를 선택합니다. 처음 한 번은 Python 3.12 이상이 필요하며, 공개 라이브러리를 설치합니다.
4. 같은 폴더에 생기는 `-채움.xlsx`를 엽니다. 원본과 임장·메모는 보존합니다. 다시 실행할 때는 새 결과 이름을 쓰거나 완성본을 선택하세요.

API 키가 필요하지 않습니다. 네이버 검색으로 공개 단지 페이지를 찾고 리치고의 **지번 주소·준공년도**, 당근부동산의 **도로명 주소**를 대조합니다. 세대수·주차·용적률·건폐율·공급평형별 매물 최저호가·역 도보·시설 정보를 채웁니다. 호가는 전용면적 하나가 아닌 공급평형 묶음일 수 있어 범위를 바로 옆에 표시합니다. 30일보다 오래된 호가는 넣지 않습니다.

숫자의 출처와 조회일은 셀 메모와 **기준 및 출처** 시트에 있습니다. 사이트별 표시 반올림이 다를 수 있습니다. 대지지분은 정확한 평형의 명시된 자료가 없으면 비우며, 대지면적을 세대수로 나눠 만들지 않습니다. 주민 후기의 승강기 연결 여부는 공식 건축물 자료와 구분해 출처를 남깁니다.

**이동 시간도 자동 조회합니다.** 개인 설정에 저장된 네이버 목적지 경로를 엑셀에 함께 담습니다. 프로그램은 별도의 Edge 세션에서 각 단지의 정확한 지번 주소를 출발점으로 설정하고, 평일 오전 8시 출발·대중교통의 최적 경로를 읽습니다. 주말에 실행하면 다음 월요일을 조회합니다. 도착 시각에서 08:00을 빼 최초 대기까지 포함합니다. 원래 브라우저의 탭이나 로그인은 사용하지 않습니다. Windows의 Microsoft Edge가 필요합니다.

목적지 경로가 없는 엑셀에서는 이름만으로 임의 장소를 선택하지 않습니다. 먼저 네이버 지도에서 목적지를 확인한 대중교통 경로 링크를 `기준 및 출처`에 `네이버 목적지 · 신랑 직주`와 같은 항목으로 넣으면 다음 실행부터 재사용합니다. 네 목적지의 이름을 바꾸면 이전 경로를 함께 바꿔야 합니다. 개인 위치는 GitHub로 전송하지 않으며 경로 조회에 필요한 주소만 네이버 지도에 입력합니다.

같은 자료는 하루 동안 로컬 캐시를 재사용합니다. 많은 단지를 선택하면 오래 걸립니다. 10행마다 진행 파일을 저장하며 중단했을 때 그 파일에서 이어갈 수 있습니다. 사이트 접근 제한·로그인·보안문자가 나오면 우회하지 않고 사유를 출처 시트에 기록합니다. 모든 빈 칸이 반드시 채워지는 프로그램은 아닙니다.

엑셀 버튼으로 실행하려면 먼저 `fill.cmd`를 한 번 실행한 다음, 본인의 매크로 통합문서에 `FillEstate.bas`를 가져오고 버튼에 `FillEstateWorkbook`을 연결합니다. 매크로 보안 설정을 전역으로 낮출 필요는 없습니다. 버튼은 같은 자동 채우기 프로그램을 실행합니다.

개발자 실행 예:

```powershell
python fill_workbook.py 비교표.xlsx --output 비교표-최신.xlsx
python fill_workbook.py 비교표.xlsx --limit 10
```
