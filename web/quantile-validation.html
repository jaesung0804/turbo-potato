어떻게 학습했나요?

단지·전용면적별 거래가 불규칙하고 적어, 시차·층·거래량·주변 가격을 함께 사용하는 LightGBM 분위수 회귀를 선택했습니다. 2021~2025년 자료로 양 끝을 학습하고 2026년 3~5월로 보정했습니다. 신고 시차 31일을 두어 7월 이후에만 적용합니다. 매월 판단 시점에 사용할 수 있는 과거 정보만 입력합니다.

기존 L1 손실 모델은 중앙값에 해당하는 목적함수를 사용합니다. 새 중앙값 후보보다 검증 결과가 좋아 그대로 유지했습니다. 낮다는 이유로 가격을 잘라내거나 중복 원본을 제거하지 않습니다. 기존 취소·직거래 제외 규칙은 별도로 유지합니다.

결과를 읽을 때

  • 여러 후보를 순차 비교한 사후 평가이며, 과거 연구에서 쓴 자료를 다시 사용했습니다. 독립된 미래 검증 결과가 아닙니다.
  • P10 아래에 실제 거래의 6.74%, P90 아래에 86.89%가 있었습니다. 각 경계가 정확히 10%·90%로 보정된 것은 아닙니다.
  • 현재 월의 거래가격 분포를 추정합니다. 미래 상승률 예측이나 증여 판정 모형이 아닙니다. 저가 거래가 많으면 중앙값도 움직일 수 있습니다.
  • 실제 거래 층으로 평가했으며 화면은 과거 대표 층 기준입니다. 개별 매물의 내부 상태와 권리관계를 확인해야 합니다.

선정 근거와 상세 기록

TFT의 다중 분위수 출력과 Chronos-2를 참고했습니다. 두 모델을 동일 자료로 직접 학습해 비교한 결과는 아니므로 우월성을 주장하지 않습니다. 구현은 LightGBM의 분위수 목적함수를 사용합니다.
