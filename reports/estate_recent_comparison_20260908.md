# 현재 실거래 비교의 기간과 거래 근거 정비

2026-09-08 검증. 가격 추정 모형의 재학습이나 새로운 예측 성능 채택은 수행하지 않았다. 기존 월별 F50를 유지하면서, 비교할 가격과 기본 탐색 조건의 의미를 바로잡은 변경이다.

## 확인한 문제와 변경

기존 현재 점수는 2026년 누적 실거래 중앙가를 2026년 9월 F50와 비교했다. 연초에만 거래된 가격도 현재의 할인 가격처럼 정렬될 수 있었다. 또한 F50 자체의 같은 평형 이력이 오래된 경우에도 주변 가격으로 추정한 값과의 큰 차이가 상위 점수로 표시됐다.

이제 비교가격은 원자료에서 현재 기준월까지 관측된 마지막 계약일을 자료 마감으로 삼고, 마감일과 그 89일 전을 모두 포함하는 정확히 90일의 중앙가다. 90일 거래가 없으면 현재 목록 점수는 미산출이며 연간 가격으로 대체하지 않는다. 연간 평균·중앙가와 거래수는 별도 통계로 그대로 보존한다. F50가 있는 평형은 비교기간에 거래가 없어도 직접 가격을 입력할 수 있다.

기본 탐색 조건은 다음 두 건수가 각각 3건 이상인 평형이다.

- F50 산출에 사용한 같은 평형의 최근 입력 이력 거래수.
- 현재 비교가격을 만드는 90일 거래수.

3건은 탐색을 위한 조건이며 정확도나 통계적 유의성을 보장하지 않는다. 가격 차이에 거래수를 곱하거나 점수를 50으로 수축하지 않았다. ‘전체 평형 보기 · 자료 희소 포함’으로 변경하면 모든 기존 평형과 계산값을 확인할 수 있다. 검색 연결 URL은 이 모드로 열려 특정 후보가 필터 때문에 사라지지 않는다.

## 자료와 시간 기준

| 항목 | 실제 값 |
|---|---|
| 원자료 | 1,144,586행 |
| 해제·직거래 등 기존 정제 후 | 1,037,893행 |
| 자료의 최신 계약일 | 2026-09-07 |
| 최근 비교기간 | 2026-06-10 ~ 2026-09-07, 양끝 포함 90일 |
| 비교기간 거래 | 52,703건 / 20,396개 평형 |
| F50 기준월 / 입력 마감 | 2026-09 / 2026-08-01 |
| F50 입력 ‘90일’ 이력 | 2026-05-03 ~ 2026-08-01 |
| F50 대표층 이력 | 2025-08-02 ~ 2026-08-01, 365일 중앙층 |

F50 입력의 기존 `n90`는 ‘입력 마감으로부터 90일 이내’이며 마감−90일을 포함하므로 달력 날짜로는 91개다. 이 피처 정의와 학습 계수는 바꾸지 않고 실제 시작·마감 날짜를 공개한다. 새 비교기간은 달력 날짜로 정확히 90개다. 최근 비교 거래의 층으로 F50를 다시 산출한 것이 아니므로, 상세 화면에서 대표층과 개별 거래의 실제 층을 구분해서 읽도록 했다.

자료 마감은 **관측된 최신 계약일**이다. 최종 공개 원자료의 해제 상태를 사용한 집계이며 실제 공개일별 원본을 복원했다는 뜻이 아니다. 입력 31일 지연 가정도 그대로 유지했다.

원자료 SHA-256: `8d26deabbb65da542427c9b754e940cd2ec77fee0e8c61140eca02e31e5cb61f`.

가격 비교가 가능한 20,386개 중 최근 비교 거래가 1건인 평형은 9,770개, 2건인 평형은 4,184개다. 표본 부족은 현재 시장 자료 자체의 중요한 특성이므로 이 수치를 숨기거나 임의의 거래를 보충하지 않았다.

이 검증은 동결된 9월 F50 전체 산출물에 동일 원자료의 새 비교가격을 결합해 수행했다. 새로운 가격 예측 정확도의 향상을 입증하는 백테스트가 아니다. 90일이 모든 단지에 최적인 기간이라고 주장하지 않는다.

## 사용자 사례: 시흥시 거모동 동보 25.12㎡

- 정확한 식별키: `시흥시 거모동 612-1 동보 | 25.12㎡`.
- 최근 비교기간 15건, 중앙가 **0.52억**. 기간 내 첫 거래 2026-06-11, 마지막 거래 2026-08-26.
- 기존 F50 **0.5181억**, 대표 10층, F50 입력 이력 15건.
- 가격 비교점수 **48.2점**, 기준가 대비 **−0.37%**.
- 0.5181억을 직접 입력하면 정확히 **50점**.
- 이 사례는 최근 90일 중앙가가 우연히 연간 중앙가와 같아 점수는 그대로다. 이제 화면과 CSV에 비교기간을 명시한다.

## 오래된 이력 사례: 마포구 망원동 리츠 53.65㎡

정확한 식별키는 `마포구 망원동 483-3 리츠 | 53.65㎡`이며, 정제 원자료에서 다른 단지나 다른 면적이 섞인 것은 확인되지 않았다. 같은 키의 거래는 총 2건이다. F50 입력 마감 이전의 마지막 거래는 **2021-07-03** 한 건이며 9월 월초 기준 **1,886일**이 지났다. 이후 **2026-08-08, 3층, 6.47억** 거래는 8월 1일 입력 마감 뒤라 F50 입력에서 빠지는 것이 기존 지연 가정에 맞다.

과거 365일 거래가 없으므로 대표층은 미확인이고 최근 입력 거래수는 0이다. 기존 모형은 이때 주변 단지·지역의 가격을 기준으로 추정을 이어갈 수 있어 F50가 **9.4307억**, 비교점수가 **90점**으로 남았다. 이 한 건을 확인한 범위에서는 키 매칭 오류나 해당 거래가격의 입력 누출이 원인이 아니다. 같은 평형의 최근 관측 없이 산출된 가격 차이를 강한 추천으로 읽게 했던 것이 문제다.

이번 변경은 해당 점수를 임의로 낮추지 않는다. 전체보기에서는 계산값·거래수·미확인 층·경과일을 함께 표시하고, **기본 목록에서는 제외**한다. 최근 자료가 희소한 F50의 정확성을 해결했다고 주장하지 않는다.

## 데이터 계약과 화면 일치

`estate_nowcast_release.attach_nowcast`에서 이미 로드한 정제 거래 프레임을 `attach_recent_comparison_prices`에 전달한다. 원자료를 다시 로드하지 않고 한 번의 기간 필터와 식별키별 집계로 끝낸다.

- `recent_price_comparison`: 기간, 마감일, 양끝 포함 여부, 건수, 중앙가, 첫·마지막 계약일, 산출 상태.
- `valuation_comparison`: 동일 비교가격·점수·할인율, 비교기간·건수, 근거 구분.
- 모델 메타: 원자료 해시, 전체 창 거래수·평형수, 기본 탐색 조건.
- `current_valuation`: 입력 이력 시작·마감, 대표층 산출기간, 기존 F50·계수 유지.

목록·지도·점수 필터·최신 연도 가격 필터·직접 입력·CSV는 동일한 비교 데이터 계약을 사용한다. CSV는 연간 통계와 최근 비교기간, 기준가 입력기간, 각각의 거래수와 자료 희소 여부를 별도 열로 보존한다. 과거 연도 예산 필터는 해당 연간 중앙가를 사용한다.

검증 코드는 90일 시작·종료 경계, 기준월 이후 자료 차단, 빈 기간의 연간 자동 대체 금지, 거래수 조건 변경 시 점수 불변, F50 입력 동등성, 기본 필터의 해제와 전체 조회 보존, 동일 비교가격의 예산 필터 사용을 검사한다. 전체 집계와 사례 원자료 요약은 같은 이름의 JSON 보고서에 기록했다.
