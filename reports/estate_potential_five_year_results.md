# 5년 잠재력 모형: 실행 완료, 이번 사양 미채택

2026-09-08. **2006~2015년 실거래 740,326행을 추가 확보하고, 실제 5년 모형의 순차 학습·검증을 끝냈다. 이번 사양은 사전 기준을 통과하지 못해 현재 18~24개월 후보를 유지한다.** 실행이 오래 걸려 결과를 확인하지 못한 상태가 아니다. 5년 예측 자체가 불가능하다는 결론도 아니다.

사용자의 목적은 5년이 되기 전에 다른 단지보다 강하게 재평가될 후보를 찾는 것이다. 따라서 현재 24개월 상대 재평가 후보를 활용하는 방향은 유지하며, 모든 후보를 정확히 5년 보유하도록 유도하지 않는다.

## 실제 확보와 보존

서울 25개 구·광명, 2006-01~2015-12의 3,120개 지역·월을 완전히 수집했다. 취소 거래와 전체 페이지를 포함한 원본 740,326행이다. 기존 2016~2020년 477,522행과 계약 기간이 겹치지 않게 결합해 과거 원본 1,217,848행을 만들었다. 별도의 2021년 이후 수도권 자료와 연결할 때도 계약 기간 중복을 검사했다. 원본·압축본 지문을 확인했으며 [출처와 결합 기록](estate_potential_five_year_sources.json)을 저장했다.

2006~2020년 자료에서 취소 등을 제외한 사용 행은1,214,440개이며 전부 거래 구분이 미상이다. 따라서 없는 필드로 과거 직거래를 구분·제외했다고 할 수 없다. 이는 과거 자료의 품질·범위 제약이며 이번 성능 미달의 원인이라고 확정하지 않는다.

새 원본은 Git의 `estate-history-extended-state` 브랜치, 커밋 `e1e48354f7cb2f15f2b4c045c7ce48569869688b`에 영구 보존했다. 수집과 Git 보존은 성공했고, 이후 부가 Actions artifact 업로드가 HTTP403으로 실패해 전체 워크플로 상태는 실패로 표시된다. 분석은 성공적으로 보존된 Git 원본을 내려받아 사용했다. 전체 작업 성공과 부가 업로드 실패를 혼동하지 않는다.

## 결과를 보기 전에 기준을 고정했다

[사전 기준](estate_potential_five_year_protocol.md)은 추가 원본 도착과 5년 분석 전에 별도 Git 커밋 [`0fef1ed9f6effb4b1c7fa08ab1e6e399c1a8fe35`](https://github.com/jaesung0804/turbo-potato/commit/0fef1ed9f6effb4b1c7fa08ab1e6e399c1a8fe35)에 보존했다. 변수·트리 설정은 기존 후보와 같고, 사후에 임계값을 낮추거나 가중치를 바꾸어 통과시키지 않았다.

2007년 1월부터 반기 판단 시점을 만들었다. 입력은 180일, 결과는 **54~60개월 뒤의 마지막 6개월 거래 중앙값**이며 동일 평형 매매가 3건 이상이어야 한다. 전체 결과 기간과 가정한 신고 지연이 끝난 이전 라벨만 학습했다. 충분한 학습자료가 있는 2013-07~2021-07에 실제 모형 시험 17개가 가능했다. 단순 소외·저가·추세 규칙까지 포함하면 107개 방법·시점 평가이며, 학습자료 부족으로 생략한 경우도 13개 기록했다.

## 사전 기준 판정

| 항목 | 사전 기준 | 실제 결과 |
|---|---|---|
| 공통 판단 시점 | 모델·소외 후보 모두 관측 단지20개 이상, 결과 관측률50% 이상인 시점 최소6개 | **1개** |
| 양의 상대 변화 | 공통 시점 중 3분의2 이상 | **0/1개** |
| 단순 소외 후보보다 높은 상대 변화 | 시점별 중앙값의 동일 가중 평균이 소외 후보보다 높음 | **모델 -0.65%, 소외 후보 +1.00%** |
| 순위와 실제 결과의 관계 | 공통 시점 Spearman 중앙값 >0 | **-0.095** |

기준을 모두 만족하는 유일한 공통 비교 시점은 2013-07이다. 이를 시장 전체를 대표하는 장기 성과로 일반화하지 않는다. 첫 단계에서 이미 탈락했기 때문에 추가 일률61일 지연 실험은 진행하지 않았다. 이 사양의 5년 후보를 추가하는 데 필요한 근거가 없다는 판정이며, 원수치는 [5년 전체 평가](estate_potential_five_year.json), 기계 판정과 자료 지문은 [요약](estate_potential_five_year_summary.json)에 있다.

공통 관측 기준을 떠나 기술적으로 측정된 결과도 강하지 않았다. 예를 들어 2014-01 상위346개 중146개에서 관측한 상대 변화 중앙값은 -1.77%, 2015-07은523개 중132개에서 -7.38%, 2016-01은528개 중140개에서 -5.91%였다. 최근 일부 시점에 양수인 결과가 있어도 앞선 실패와 미관측을 지우지 않았다.

## 무엇이 부족했는가

**5년 뒤의 좁은 6개월 구간에서 정확히 같은 평형의 거래가 3건 이상이어야 하는 목표가 결과 관측을 크게 줄였다.** 여기에 같은 구·면적 구간의 다른 단지 최소5개라는 비교군 조건이 붙는다. 예컨대 2018-01의 전체 진입 후보5,220개 중 결과 기간에 거래3건을 충족한 평형은107개, 비교군까지 갖춰 상대 결과가 계산된 것은9개뿐이었다. 반면 2015-01에는 전체4,155개 중2,707개가 상대 결과를 계산할 수 있었다. 이 차이를 단일한 고정 신뢰도로 뭉개지 않았다.

모형 선별 자체의 결과 관측률도 낮았다. 2015-01에는 전체 후보의 상대 결과 관측률이65.2%였지만 모델 상위 후보에서는39.5%였다. 따라서 시장의 거래 부족만으로 설명할 수 없고, 모델이 선택한 후보의 거래·표본 특성과 목표 정의를 함께 재설계해야 한다. 재개발·명칭 변경·자료 연결 변화가 각각 얼마나 기여했는지는 이번 분석에서 분해하지 않았으므로 확정 원인으로 주장하지 않는다.

다음 연구 가설은 **48~60개월 또는 매 시점 직전12개월의 더 넓은 결과가격**, 그리고 **5년 전에 정해진 상대 재평가 수준에 처음 도달하는 기간**이다. 결과 관측량과 실제 의사결정에 맞는 목표인지 새 사전 기준으로 비교해야 한다. 이번 실패한 시험의 기준을 즉석에서 완화해 좋은 결과가 나올 때까지 반복하지 않는다. 사후 최고가에 팔았다고 가정하는 방식도 사용하지 않는다.

## 현재 반영

잠재력 페이지에는 실제 5년 실험의 완료 상태와 미채택 사유를 별도로 표시한다. 기존 24개월 v2의 3,699개 후보, 예측값, 자료 지문과 검증표는 바꾸지 않는다. 현재 저평가 점수에도 5년 예측값을 더하지 않는다.

재현: `merge_estate_potential_history.py`로 두 원본 지문을 확인하고 결합한 뒤 `analyze_estate_potential_horizons.py --history .work/history/transactions_2006_2020.csv --origin-start 2007-01-01 --origin-end 2021-07-01 --horizons 60 --regimes historical_policy --output reports/estate_potential_five_year.json --cache .work/potential-five-year`, 이어 `summarize_estate_five_year.py`를 실행한다. 시험 결과는 최종 수정 자료에 신고기한을 가정한 회고 연구이며 당시 최초 공개본의 완전한 재현은 아니다.
