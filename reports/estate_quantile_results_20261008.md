# 로컬 분위수 모델 비교 결과 — 2026년 10월 8일

`estate-quantile-capital-v1`을 채택했다. 기존 L1 중앙값 모델을 유지하고, 600개 트리·31개 잎의 LightGBM P10/P90을 학습한 뒤 2026년 봄 자료로 보정한 조합이다. 중앙값은 같은 입력에서 기존과 정확히 같다. 실제 거래의 낮은 가격과 반복 원본 행은 보존했다.

## 동일 거래 비교

최종 비교 기간은 **2026년 7~8월, 37,296건·8,731개 단지**다.

손실 개선은 약 0.4%로 작다. 평균 범위는 약 7.5% 넓다. 개선을 중앙값 정확도 상승으로 해석하지 않는다. 지역·월·저층·거래 희소 집단은 사전 진단 범위인 70~90%를 통과했다. 서울 81.11%, 경기 79.02%, 인천 84.51%다.

9월은 신고 지연이 남아 있는 별도 진단이다. 12,778건·5,387개 단지에서 손실은 0.01793577→0.01776802, 포함률은 78.01→81.47%, 중앙값 MAE는 0.34017619억으로 동일했다. 상세 집단과 개별 분위수 손실은 [수치 보고서](estate_quantile_results_20261008.json)에 있다.

## 학습·보정·선택 경과

- 검증한 로컬 원본 1,160,508행(2021-01-01~2026-10-06), 기존 정책 적용 후 1,052,567행. 원본 SHA-256: `8e33df9b92e9680b7ba0e736e190effd46c7be60eaa43c77805a34eac4d9b6a7`.
- 학습: 2021년 3월~2025년 12월 중 3~12월. 과거 가격·층·거래량·인근 거래를 입력하며 가격에 따른 제거·가중치 변경은 없다. 양의 시간 가중치 반감기는 48개월이다.
- 기존 중앙값은 더 긴 2007년 이후 이력에서 선정한 지역별 L1 모델이다. 후보와 학습 기간이 다르므로 공통 평가 거래에서 비교했다.
- 보정: 2026년 3~5월. 신고 시차 31일을 포함해 2026년 7월부터 사용 가능하다. 모델의 `trained_through=2026-06-30`은 보정 자료의 사용 가능 시점을 포함하며 기본 학습 종료는 2025-12-31이다.
- 처음 계획한 220트리·23잎 후보와 2025년 보정, 기존 중앙값 유지, 최근 오차에 조건부 꼬리 학습은 손실 기준을 통과하지 못했다. 600트리·31잎은 손실을 개선했지만 보정 전 포함률 74.0%로 탈락했다. 최근 보정을 결합한 최종 조합이 모든 진단 기준을 통과했다.
- 초기 평가 기간 3~8월 중 봄을 보정에 사용함에 따라 최종 평가는 7~8월로 변경했다. 서로 다른 기간의 후보 손실을 한 순위로 비교하지 않는다. 날짜별 후보 결과는 수치 보고서에 보존했다.
- 중앙값과 꼬리가 교차하면 꼬리만 중앙값에 맞춰 제한한다. 중앙값을 정렬 과정에서 바꾸지 않는다. 배포 연결은 정렬 위치가 아닌 단지·평형 식별자로 연결한다.

## 한계

2026년 자료는 기존 연구에도 쓰였고 여러 후보를 순차적으로 검토했다. **독립 홀드아웃이나 사전 등록한 단일 실험이 아니다.** 유의성·미래 성능 개선을 입증했다고 주장하지 않는다. 당시 공개된 원본 버전 전체가 없어 신고 시차는 모사한 것이며 사후 정정·해제 상태의 영향이 남는다.

관측 누적 비율은 P10 6.74%, P50 46.32%, P90 86.89%다. 중앙 80% 포함률은 좋아졌지만 각 꼬리의 보정은 불완전하다. 분위수는 급매와 특수 거래가 섞인 분포를 보여주며 증여 여부를 판별하지 않는다. 저가가 충분히 많으면 중앙값도 움직인다.

예측은 현재 월의 대표 층 거래가격 분포다. TFT/Chronos-2처럼 여러 미래 시점을 예측하는 모델을 직접 실험한 결과가 아니다. 희소·불규칙 거래에 공통 설명변수를 쓰는 모델부터 실제 비교했다.

## 재현·산출물

[로컬 실행 지침](../docs/local-model-and-release.md)을 따른다. Python 3.12, LightGBM 4.6.0(Windows)에서 실행했다. 소스·특징·기존 모델·새 모델 해시와 환경은 수치 보고서 및 [채택 명세](../metadata/nowcast_quantiles_2026.json)에 있다.

공개 집계 원본은 1,160,521행이며 로컬 검증 원본보다 13행 많다. 따라서 이번 배포는 공개 카탈로그·기간별 집계·계약 평가 원장을 보존하고 현재 월의 모델 출력만 교체한다. 추론 원본은 `nowcast.inference_source`에 별도 기록한다. 공개 집계의 자료일과 수집일을 로컬 실행일로 바꾸지 않는다.

같은 평가 입력에서 중앙값 예측 배열이 기존 모델과 정확히 같음을 다시 검사했다. 실제 공개본과는 추론 원본·동일 날짜 거래 순서 차이가 있어 34,240개 중 117개 평형의 중앙값이 달라졌다. 변경분의 상대 차이 중앙값은 약 0.056%, 최대는 3.94%다. 이를 새 중앙값 모델의 성능 향상이라고 해석하지 않는다. 현대1의 네 평형은 공개 중앙값과 같다.
