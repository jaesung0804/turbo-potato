# 수도권 장기 매매·전세 확장: 수집 후 검증 분리 기준

2026-09-09. **이 문서는 수집 완료·자료 품질·새 모형의 개선을 전제하지 않는다.** 서울·경기·인천의 매매 2006-01~2026-09, 전세의 공개 가능한 최대 과거를 요청한 데 따른 수집 감사와 후속 검증 설계다. 이번 단계에서는 새 모형 실험·운영 반영을 하지 않는다. 아래 분리표와 입력 지문을 결과 계산 전에 보존한다.

## 1. 먼저 확인할 수집 범위와 자료 정합성

공식 공개 안내 기준 매매는 2006-01부터, 전월세는 2011-01부터의 확정일자 자료와 2021-06부터의 임대차 신고 자료다. **2006~2010년 전세는 이 출처의 미제공 구간**이며 0건·전세 수요 없음으로 기록하거나 역산하지 않는다. 실제 확보한 최초·최종 계약월은 요청 범위와 별도로 표시한다. 안내 출처: [국토부 공개 안내](https://rt.molit.go.kr/pt/info/info.do?mobileAt=).

| 감사 항목 | 고정 처리와 통과 조건 |
|---|---|
| 지역·월 완전성 | 자료 종류×당시 유효 지역 코드×계약월의 요청·성공·행수·페이지/파일 완결·실패 사유를 원장에 남긴다. 확인된 빈 응답, 공개 대상 밖, 미수집을 구별한다. 2026-09는 진행 중인 월로 표시하고 완결 월의 거래량·가격과 직접 비교하지 않는다. |
| 시군구 개편 | 경기·인천의 분구·통합·명칭/코드 변경은 적용 시작·종료일이 있는 대응표로 관리한다. 역사 코드와 현재 코드를 모두 보존하며, 현재 시군구 목록만으로 과거 요청 범위를 만들지 않는다. 단지·법정동/지번·정확한 전용면적 연결을 검사하고, 다대다·불명확 연결은 임의 합치지 않는다. |
| 경계와 비교군 | 같은 구·15㎡ 구간의 다른 단지라는 기존 정의를 유지한다. 주 분석은 판단일 당시 유효 경계에 후보와 비교군을 고정한다. 경계 변환이 불가능한 원점은 별도 사유로 남긴다. 현재 경계로 재집계한 비교는 사전 지정 민감도이며 더 좋은 경계를 사후 선택하지 않는다. |
| 중복·정정·취소 | 새 다운로드와 기존 서울 전월세·매매 파일을 단순 합산하지 않는다. 원본별 지문·수집일·행 서명을 보존하고 같은 지역·계약월은 검증된 한 출처를 우선 사용한다. 겹치는 출처는 정합성 감사에 사용한다. 고유 계약 ID가 없으면 공개 행 서명은 계약 수가 아니며, 동일 조건의 별개 계약과 중복을 완전히 구분했다고 주장하지 않는다. 취소·정정 반영과 거래 구분 미상 건수를 별도 집계한다. |
| 전세 정의·제도 전환 | 아파트·월세액 0·양의 보증금을 순수 전세로 고정한다. 보증부 월세는 따로 둔다. 신규·갱신·미상, 갱신요구권 사용 여부는 원본에 있는 범위에서 분리하며 미상을 신규로 채우지 않는다. 2011~2021-05 확정일자 구간과 2021-06 이후 혼합 신고 구간의 필드 가용성·중복·지역/금액대별 관측률을 먼저 비교한다. 제도 경계의 건수 증가를 수요 증가로 바로 해석하지 않는다. |

## 2. 계약 시점과 실제 사용 가능 시점을 분리한다

매월 판단일 `t`에는 계약일이 아니라 **사용 가능일이 t 이전인 입력만** 사용한다. 매매의 기존 기본 가정은 계약별 2020-02-21 이전 +61일, 이후 +31일이며 전체 +61일도 고정 민감도로 남긴다. 이것은 실제 공개 지연을 측정한 값이 아니다. 전세 확정일자·신고자료에 매매 지연 규칙을 자동 적용하지 않는다. 계약일·접수/신고일·자료 공개/수정일·최초 수집 관측일을 가능한 만큼 각각 보존한다.

이번 수집은 현재 시점의 정정본이다. 과거 최초 공시본을 복원했다고 부르지 않는다. 전세 최초 공개 시점을 복원할 수 없는 구간은 계약일 기반 회고 분석으로 명시하고, 공개일을 입증한 자료만 사용하는 보수적 비교를 별도로 둔다. 파일 수정일이 이번 수집 시점뿐이라 과거 입력이 모두 제외되면 그 결과를 그대로 보고한다. 공개 시점 가정을 바꿔 통과시키지 않는다. 향후 새 수집부터 원본 스냅샷과 최초 관측 원장을 축적한다.

## 3. 이미 본 자료와 새 검증을 나눈다

서울·광명의 2006~2020 매매는 이미 5년 및 24·36·48·60개월 경로 시험에 사용됐다. 서울 2016~2025 접수 전월세, 수도권 2021년 이후 매매도 가격·잠재력 시험과 일부 겹친다. 기존 54~60개월 시험과 12개월 결과창 경로 시험의 미통과 기록, 24개월 v1/v2의 서로 다른 결과를 그대로 보존한다. **같은 계약을 다시 받거나 같은 목표를 다른 창으로 계산하는 것은 새 독립 시험이 아니다.**

성과를 보기 전에 `단지 키×판단일×목표 기간×진입/결과 창`과 사용 원본을 기준으로 기존 실험과의 중복 원장을 만든다. 가격 평가·피처·학습 목표·비교군·사례 검토 사용 여부까지 표시한다. 다음 분리를 확정하고 목록·코드·지문을 보존한다.

| 구획 | 용도·금지 사항 |
|---|---|
| A. 기존 서울·광명 및 이미 평가한 수도권 표본 | 기존 고정 사양의 재현·정정 영향·범위 확대 진단용. 같은 후보/같은 원점의 결과와 신규 편입 후보 결과를 분리해 자료 교체 효과와 모집단 변화 효과를 구별한다. 모형·기간 선택 근거로 이미 사용됐으므로 독립 검증 수에 더하지 않는다. |
| B. 경기(광명 제외)·인천의 지리 검증 | 전체 해당 지역을 사전에 묶어 두고 기존 서울·광명에서 고정한 잠재력 사양을 한 번 평가한다. 해당 지역의 목표행과 해당 단지가 포함된 학습 비교군은 학습·튜닝에서 모두 제외한다. 평가 시점 이전 지역 거래는 후보 자신의 입력과 지역 비교 피처를 만드는 데 사용할 수 있다. 2021년 이후 자료가 기존 수도권 가격 실험에 쓰였다면 이를 명시하고 완전 미열람 외부시험이라고 부르지 않는다. 중복 없는 과거 원점과 중복 원점을 따로 보고한다. |
| C. 앞으로 기록할 시간 검증 | 이번 설계·자료·모형을 고정한 이후의 월별 예측을 생성일·입력 마감·지문과 함께 덮어쓰기 없이 보존한다. 기존 2026-09 v1/v2 예측은 그대로 둔다. 새 확장 사양은 별도 버전으로 기록하고 목표 성숙 후 평가한다. 이후 수정한 사양은 새 예측부터 별도 계열로 시작한다. |

B의 결과를 보고 다시 설계하면 B도 개발 자료가 된다. 그 결과에서 통과 기간·지역·컷오프를 골라 재시험하지 않는다. 추가 전세 변수의 효과는 먼저 A에서 가격·거래만의 고정 모형과 같은 후보·원점·층·라벨을 사용해 비교하고, 변수 목록·결측 처리·모형 설정·주 목표·통과 기준을 별도 실행 문서로 고정한 후 B를 한 번 연다. B의 가격 기반 결과를 이미 확인했으면 그 사실을 기록하고 전세 실험을 새 독립 확인시험으로 부르지 않는다. 전세가 연결되는 공통 표본의 추가 효과와 전체 후보에서의 커버리지 손실을 함께 보고한다.

## 4. 시간 누수·관측 부족·진입가격 오차를 재검증한다

- **성숙 범위:** 각 판단일 학습에는 결과창 종료와 가정 공개 지연이 모두 지난 이전 라벨만 쓴다. 무작위 행 분할은 사용하지 않는다. 검증 시작 이후 결과 거래를 공유하는 학습 라벨은 제거한다. 같은 단지·겹치는 반기 원점·결과창을 독립 표본으로 세지 않으며 불확실성은 단지와 시간 블록의 의존성을 반영한다.
- **24/60개월 상한:** 2026-09-09가 실제 자료 마감일이라고 해도 +31일 가정에서 결과창 종료는 2026-08-09까지다. 따라서 24개월 원점의 이론상 상한은 2024-08-09, 60개월은 2021-08-09다. +61일이면 각각 2024-07-10, 2021-07-10이다. 기존 반기 원점은 두 가정 모두 최대 2024-07-01/2021-07-01이며, 실제 수집 완전성이 부족하면 더 앞당긴다. 기간별 성숙 원점 수·학습 충족 원점 수·관측 충족 원점 수를 별도로 보고한다. 2026년 판단의 장기 성과는 아직 없다.
- **진입점 측정오차:** 기존 180일·동일 단지/정확한 면적·3~20층·최소 3건을 유지한다. 진입가격이 낮게 측정되면 저가 신호와 이후 변화가 동시에 커지는 기계적 반등을 점검한다. 진입 거래 수·가격 산포·마지막 거래 경과일·전후 층 구성별 오차를 보고하고, 충분 표본 후보에서는 고정된 거래 분할로 신호 계산과 진입가격 측정을 분리한 민감도를 수행한다. 분할 불가 후보를 조용히 빼거나 최소 거래수를 낮추지 않는다.
- **미관측 라벨:** 진입 모집단과 상위10%를 결과 확인 전에 고정한다. 미래 무거래·최소 건수 미달·단지/면적 연결 실패·비교군 부족·아직 미성숙을 구분한다. NaN을 0·실패로 바꾸지 않는다. 지역·시기·유동성·신규/갱신 가용성별 전체 후보와 선정 후보의 관측률을 함께 보고한다. 넓은 결과창이나 다른 면적 연결은 기존 시험의 성공으로 소급하지 않는다.

## 5. 다음 실행 전에 확정할 판정과 산출물

현재 가격 정확도와 미래 상대 재평가를 별도 질문으로 유지한다. 잠재력의 주 목표는 기존 v2의 **18~24개월 상대 변화**로 고정하고, 기존 54~60개월 및 네 체크포인트 경로 모형은 각 원래 사양의 재현·범위 확대 진단으로 구분한다. 네 기간 평균으로 24개월 결과를 대체하지 않는다. 모든 모델은 단순 소외·주변 대비 저가·추세 규칙과 동일 후보·원점에서 비교한다.

새 B 실행의 성과를 열기 전에 전용 사전 기준에 최종 입력 지문, 대상 지역/원점 목록, 고정 모형, 주 비교 지표와 수치 통과 기준, 충분관측 조건, 민감도·중단 순서를 기록해야 한다. 기존 5년/경로의 기준은 낮추지 않는다. 후보 관측률·정합성 감사는 먼저 할 수 있으나 부족하면 검증 불가로 남긴다. 이번 문서만으로 신규 모형의 승격 기준이 확정됐다고 간주하지 않는다.

수집 원장·경계 대응표·출처 간 차이·실험 중복표·분할 목록·원점별 성숙/관측표·실험 지문을 남긴다. 자료 증가가 거래 절벽의 미관측이나 당시 공개 시점 부재를 자동 해결하지는 않는다. 개선이 관측되더라도 추가 지역·추가 과거·정정본·전세 입력 각각의 효과를 구별하고, 이번 수집과 회고 시험만으로 운영 가격·후보·배포를 바꾸지 않는다.
