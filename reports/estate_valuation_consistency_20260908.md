# 현재 가격 비교와 계약 당시 저평가 평가의 일치 검증

작성: 2026-09-08. 원천 실거래: 2026-09-07까지. 상세 수치는 같은 이름의 JSON에 보관한다.

## 확인한 문제와 수정

실제 문제 단지는 **시흥시 거모동 612-1 동보 전용 25.12㎡**였다. 2026년 29건의 실거래 중앙가는 0.52억, 2026-09 월별 50점 기준가는 0.5181억인데, 목록은 다른 연간 모형의 83.4점을 표시했다. 기준가격과 점수의 모형·시점을 다르게 연결한 문제다.

현재 가격 비교는 목록·지도·필터·입력 계산기·CSV에서 `valuation_comparison`만 사용한다. 월별 기준가가 없으면 연간 점수를 대신 표시하지 않는다. 과거 연간 모형 결과는 감사용으로 보존한다. 표시된 만원 단위의 가격을 먼저 확정한 뒤 점수를 계산하여, 화면에서 본 가격을 그대로 재입력해도 같은 결과가 나온다. 연간 실거래 총액 집계도 종전 10만원 단위에서 만원 단위로 정밀도를 높인다.

| 동일한 가격 비교 | 결과 |
|---|---:|
| 기준가 0.5181억에 0.5181억 입력 | 50.0점 |
| 기준가 0.5181억에 0.52억 입력 | 48.2점 |
| 기준가 대비 할인율 | −0.37% |
| 종전 목록의 연간 점수 | 83.4점 — 현재 비교에서 제거 |

할인율은 `(F50 − P) / F50 × 100`이다. 점수는 기존 월별 오차 스케일 0.08094263165106064를 유지한 `50 + 40 × tanh(log(F50/P)/scale)`의 표시 지수다. 가격 차이를 점수로 읽기 쉽게 옮긴 것이며 확률로 보정한 값은 아니다. 거래수로 이 가격 차이를 다시 줄이지 않고 거래수·최근성·거래일 수를 자료 품질로 따로 보여준다. 학습된 가격 모형의 계수를 바꾸어 50점을 맞춘 것이 아니다.

## 거래 당시를 평가하는 별도 계산

현재 월 기준가와 연간 실거래 중앙가를 비교하면 가격·점수의 일치는 해결되지만, 과거 거래 당시 얼마나 낮은 가격이었는지는 알 수 없다. 이를 위해 **2026년 3월부터 9월 7일까지의 실제 계약 134,337건**을 계약월별로 재평가했다.

- 모형은 2025-12-31까지 학습한 기존 검증 완료 월별 모형을 고정했다. 학습에 사용한 2025년 거래를 검증 거래처럼 다시 평가하지 않는다.
- 각 계약월의 시작일에서 31일 앞선 계약까지 가격·거래량 피처를 만든다. 해당 계약의 가격이나 같은 달 나중에 계약된 가격은 입력하지 않는다.
- 실제 거래의 층을 조건으로 기준가를 계산한다. 현재 시점 비교의 대표 층과 구분한다.
- 1~2월은 현재 모형의 지원 대상이 아니므로 별도 연간 모형을 섞어 채우지 않는다.
- 최근 개별 계약 3건은 계약일·층·계약가·당시 기준가·할인율·점수를 함께 공개한다. 월별 집계는 계약별 할인율·점수의 중앙값이며, 중앙 거래가와 중앙 기준가의 비율로 계산한 점수와 같다고 주장하지 않는다.

| 계약월 | 평가된 실거래 건수 |
|---|---:|
| 2026-03 | 22,204 |
| 2026-04 | 25,830 |
| 2026-05 | 26,472 |
| 2026-06 | 23,498 |
| 2026-07 | 21,311 |
| 2026-08 | 13,681 |
| 2026-09, 7일까지 | 1,331 |
| 합계 | **134,327** |

10건은 사용 가능한 가격 기준이 없어 미산출했다. 총 30,457개 평형을 평가했다. 해당 기간 실제 층 조건의 평균 절대 가격 오차는 0.4988억, 중앙 절대 비율 오차는 4.170%다. 기간이 다른 예전 실험과 이 수치를 직접 비교하여 새 모형의 성능 향상이라고 해석해서는 안 된다. 이번 변경은 모형 계수 재학습이 아니라 점수 연결 수정과 계약 당시 평가의 실제 적용이다.

동보 25.12㎡의 실제 계약은 다음처럼 구분된다.

| 계약 | 계약가 | 해당 계약월·층의 기준가 | 할인율 | 점수 |
|---|---:|---:|---:|---:|
| 2026-08-24, 11층 | 0.5200억 | 0.5192억 | −0.15% | 49.2 |
| 2026-08-24, 16층 | 0.5050억 | 0.5190억 | +2.70% | 63.0 |
| 2026-08-26, 4층 | 0.5300억 | 0.5089억 | −4.15% | 31.5 |

동보의 3~8월 계약 24건 전체 점수 중앙값은 68.6이지만 8월 점수 중앙값은 49.1이다. 예전 거래 당시의 할인과 지금의 가격 비교가 다른 질문임을 보여준다. 따라서 68.6을 현재 기준가 0.5181억 옆의 대표 점수로 표시하지 않는다.

## 검증과 재현

회귀 검증은 사용자가 제시한 숫자, 표시 가격 재입력, 가격에 따른 점수 단조성, 표본 수와 가격 차이의 분리, 미산출 시 연간 점수 대체 금지, Python·JavaScript의 반올림 및 점수 일치를 포함한다. 계약 가격을 크게 바꾸거나 같은 달 미래 거래 가격을 추가해도 해당 계약의 기준가가 바뀌지 않는지 검사했다.

전체 공개 최근 계약 **64,800건**의 가격을 재입력해 점수가 모두 일치함을 확인했다. 모든 평형의 월별 건수 합계와 전체 건수, 모든 계약월의 31일 컷오프도 일치한다.

실제 홈페이지 빌드에 연결된 최신 연도 **33,320개 평형 전체**도 검증했다. 현재 기준가를 산출한 33,310개 평형에서 표시 가격 재입력, 기준가 입력 시 정확히 50점, 월·컷오프·할인 방향의 일치가 모두 통과했다. 기준가가 없는 10개는 점수도 미산출이다. 평형별 비교가격 21개, 합계 **699,510개 가격 시나리오**에서 가격이 높아질수록 점수가 높아지는 역전이 없었다. Python과 실제 브라우저와 같은 JavaScript 계산식의 점수도 **33,310개 전부 일치**했다.

| 현재 비교 대상 | 평가된 평형 |
|---|---:|
| 서울 | 12,207 |
| 경기 | 17,061 |
| 인천 | 4,042 |
| 합계 | **33,310** |

현재 기준가와의 차이가 ±1% 이내인데 종전 연간 점수가 80점 이상이었던 평형은 동보를 포함해 7개였다. 모든 평형을 대상으로 계산한 수치이며 일부 사례만 표본으로 고른 결과가 아니다. 다른 모형·표본 보정의 연간 점수와 현재 점수는 정의가 다르므로, 점수 변경 폭 자체를 가격 예측의 성능 향상 지표로 해석하지 않는다. 세부 검증 결과는 같은 이름 JSON의 `current_population_checks`에 보관한다.

```sh
python estate_valuation.py --source data/capital_area_apt_trade_transactions.csv --month 2026-09
python -m pytest -q tests/test_estate_valuation.py tests/test_estate_nowcast.py
```

결과는 `metadata/transaction_valuation_2026.json.gz`에 저장한다. 원천 SHA-256, 모형 SHA-256, 모형 명세 SHA-256, 산출월이 같으면 재사용한다. 원천이 바뀌면 다시 계산하여 새 거래를 반영한다. 31일은 관측된 실제 공개일 분포를 추정한 값이 아니라 기존 비교 실험의 가정이다. 최종 공개 자료의 해제 상태를 사용하므로 과거 공개 원본을 완전히 재현한 결과도 아니다. 이 구분은 화면과 결과 메타데이터에도 유지한다.
