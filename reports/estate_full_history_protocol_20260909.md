# 전체 과거를 유지하는 개선 비교 — 2026-09-09

1차 전체 과거 동일 가중치 결과를 본 후 사용자의 지적에 따라 설계한 탐색적 후속 연구다. "현재 모델 유지"는 과거 자료의 폐기 결정이 아니다. 과거 기간을 유지하는 학습 방식을 비교한다. 2025/2026 결과를 이미 보았으므로 아래 절차도 독립 확인시험으로 주장하지 않는다.

## 고정 비교

2007년부터 각 평가 연도 전년까지의 적격 학습 행을 모두 사용한다. 2006년은 이력 준비에 사용하고, 기존 비교의 3~12월 목표 거래 설계를 유지한다. 1~2월 거래도 이후 과거 이력에 들어간다. 취소·지번 불명확·목표 또는 과거 기준 시세 부재 같은 제외 사유와 미래 기간 학습 금지는 유지한다. 모든 원본 행을 무조건 정답으로 쓰는 뜻은 아니다.

동일 LightGBM L1, 220개 트리, 학습률 .04, 23 leaves, 최소 100행, lambda 10, seed 20260907을 유지한다. 타깃은 이미 `log(실제 ㎡당 가격) - 당시 기준 시세`다.

| 사양 | 가격 입력 | 학습 가중치 |
| --- | --- | --- |
| all_history | 기존 절대 로그 가격 | 모두 1 |
| recency_four_years | 기존 절대 로그 가격 | 평가 연도 1월 기준 경과 월에 반감기 48개월 |
| relative_uniform | 모든 가격 입력에서 해당 행의 당시 기준 시세를 뺀 로그 비율, 절대 anchor 입력 제거 | 모두 1 |
| relative_recency_four_years | 위 상대 가격 입력 | 위 반감기 48개월 |

면적·연령·거래량·층 변수는 유지한다. 실제 거래 가격이나 미래 시세로 입력을 정규화하지 않는다. 가중치는 평균 1로 맞춰 규제 강도 비교를 유지하고, 가장 오래된 행까지 모두 양수인지 검증한다. 이 설정은 결과 전에 고정하며 추가 반감기·하이퍼파라미터 탐색은 하지 않는다. [LightGBM의 표본 가중치 인터페이스](https://lightgbm.readthedocs.io/en/latest/pythonapi/lightgbm.LGBMRegressor.html)를 사용한다.

## 선택과 평가

2023/2024년을 개발 구간으로 쓰고 각 연도 전년까지 학습한다. 네 사양을 모두 표시한다. 세 개선 후보 중 두 연도의 MAE와 단지 균등 MAPE를 해당 연도 동일 가중치 전체 과거 결과로 나눈 네 비율의 평균이 가장 작은 후보를 선택한다. 동률은 표 순서다. 개발 결과와 선택을 저장한 뒤 선택된 후보 하나만 기존 보존 2025년 3~12월, 2026년 3~7월의 동일 325,084거래·동일 입력에 적용한다.

기존 고정, 최근 재학습, 동일 가중치 전체 과거 결과와 비교한다. 기존과 최근 대비 두 연도 모두 MAE 3% 개선, 단지 균등 MAPE 악화 없음, 지역 MAE 악화 2% 이내라는 기존 수치 기준도 그대로 계산한다. 미충족 결과도 모두 공개한다. 이 기준을 수치상 충족하더라도 재사용 표본의 탐색 결과만으로 운영 모델을 자동 교체하지 않는다.

행별 가중치 적용 수·범위·유효 표본 수, 개발/평가 예측, 선택 기록, 연구 모델을 보존한다. 현재 운영 모델과 2026년 9월 고정 전망은 유지한다. 행정 경계·단지 동일성, 최초 공개 시점 확인과 향후 고정 예측의 검증은 별도 과제다.
