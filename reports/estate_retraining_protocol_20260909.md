# 2026-09-09 매매 확장 재검증 실행 기준

사용자의 재학습·검증 실행 및 홈페이지 반영 요청에 따른 실행 문서다. 수집 단계의 `estate_capital_expansion_protocol.md` 다음 단계이며, 그 문서의 미통과 기록과 자료 구획을 유지한다. 아래 기준은 이번 실험 결과를 계산하기 전에 고정한다. 입력 파일 지문은 정규화의 행수·압축 무결성 검증이 끝난 뒤 실행 원장에 기록한다.

## 자료와 시간

- 경기·인천 2006~2020 매매 30개 연도 파일, 기존 서울 2006~2020, 기존 수도권 2021~2026 자료를 사용한다. 광명 과거 자료는 새 경기 CSV가 소유한다. 같은 지역·계약기간을 여러 출처에서 더하지 않는다. 동일 공개 행의 중복도는 별도 계약일 수 있어 보존한다.
- 원본 금액은 만원, 면적은 정확한 ㎡를 유지한다. 모델 입력은 명목 만원/㎡의 자연로그이며, 파일별 표준화·현재 시점 가격으로의 지수 환산을 하지 않는다. 모델과 함께 학습되는 전 표본 평균·표준편차도 없다.
- 과거 입력은 계약일 2020-02-21 이전 +61일, 이후 +31일을 가정한다. 최종 정정본을 사용한 회고 실험이며 실제 당시 공개본 복원이 아니다. 업로드/다운로드 관측일은 각각 보존하고 공개일로 바꾸지 않는다.
- 2026년 평가의 마지막 달은 7월이다. 8·9월의 미완결 거래량을 완결 월과 섞지 않는다.

## 현재 가격: 학습 범위 확대의 추가 효과

기존 `price_activity_floor`의 변수 33개와 LightGBM L1 설정(220 trees, .04 learning rate, 23 leaves, minimum child 100, lambda 10, seed 20260907)을 고정한다. 종속변수는 기준가격 대비 로그 잔차다.

| 사양 | 학습 자료 | 역할 |
|---|---|---|
| 기존 고정 모델 | 기존 보존 예측 | 기준선 |
| 최근 자료 재학습 | 2023년부터 평가 전년 말까지, 새 입력본 | 정정·구현/재학습 영향 |
| 전체 과거 재학습 | 2007년부터 평가 전년 말까지 | 주 후보 |
| 최근 5년 재학습 | 평가 연도 직전 5개 완결 연도 | 사전 지정 민감도 |

각 사양은 보존된 **동일한 2025년 3~12월·2026년 3~7월 거래와 입력 피처**에서 비교한다. 실제 거래 층을 아는 조건부 가격 평가다. 따라서 이 비교는 학습 자료 확장의 효과이며, 홈페이지의 대표 층 예측 정확도를 뜻하지 않는다. 기존 입력 피처의 오류/정정 영향은 2026년 고정 모델을 새로 계산한 피처에 적용한 별도 공통 표본에서 보고한다. 원본 보존 파일에 일자가 없는 경우 단지·정확면적·월·층·연령·거래금액과 중복 순번으로 공통 거래를 대응시키고 탈락 수를 공개한다.

주 지표는 거래당 총액 MAE(억원), 보조 지표는 단지 균등 MAPE, 지역별 MAE다. 주 후보의 개선 기준은 두 평가 연도 각각 기존 및 최근 재학습 대비 MAE 3% 이상 감소, 단지 균등 MAPE 악화 없음, 서울·경기·인천 각 지역 MAE 악화 2% 이내다. 단지와 연도에 걸친 의존성을 보존한 대응 단지 부트스트랩도 보고하되 독립 시장 국면의 신뢰구간으로 해석하지 않는다. 기준이 충족되어도 이미 사용한 표본의 회고 개선이므로 미래 독립 검증 성공으로 승격하지 않는다. 운영 모델을 덮어쓰지 않고 후보 사양·결과를 공개한다.

## 잠재력: 고정 사양의 범위 확대 진단

주 목표는 기존 18~24개월 상대 변화, 180일 진입 창, 동일 단지·정확 면적, 3~20층, 진입·결과 각 최소 3건이다. 다른 단지 최소 5개의 구×15㎡ 비교군을 유지한다. 학습은 서울·광명에 한정하고 두 지정 사례는 제외한다. B(경기 광명 제외·인천)의 목표나 단지가 학습 비교군에 들어가지 않게 지역별로 라벨을 만든다.

원점은 2007-01-01~2024-07-01 반기이며 결과창 성숙 후의 라벨만 학습한다. 최소 학습 500행·3개 원점을 유지한다. 기존 고정 11개 변수와 L1 120 trees, 7 leaves, minimum child 100, lambda 20, .04 learning rate, seed 20260908을 사용한다. 단순 소외·주변 대비 저가·상대 추세를 같은 진입 후보에서 비교한다. 상위 10%는 미래 거래 여부를 보기 전에 정하며 미관측 목표는 NaN이다.

역사 경계·단지 연결 감사가 미완료면 B의 주 확인시험은 **검증 보류**다. 현재 파일에 기재된 경계를 사용한 수치는 사전 지정된 회고 민감도/진단으로만 계산한다. 그 결과로 유리한 지역·원점·기준을 다시 선택하거나 수도권 운영 순위로 확대하지 않는다. 전체 B를 포함한 결과와 출처/경계 연결 손실을 공개한다. 충분 관측 기준은 원점별 선정 후보 관측률 50% 이상·관측 단지 20개 이상 및 이 조건을 충족한 원점 6개 이상이다. 미래 성과를 본 뒤 기준을 낮추지 않는다.

기존 5년·다중 경로 미통과는 유지하며 이번 24개월 진단으로 대체하지 않는다. 실제 최초 공개본·역사 경계가 확보되지 않으면 재학습만으로 그 가설들이 확인됐다고 쓰지 않는다.
