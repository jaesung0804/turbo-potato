# 경기 광명시 2006년 매매 CSV/API 중첩 감사

국토교통부 공개 CSV와 기존 API 자료의 광명시 2006년 계약을 **전행 다중집합(multiset) 비교**했다. CSV 5,304행, API 5,304행이 **내용과 중복 횟수까지 전부 일치**했다.

| 항목 | 건수 |
|---|---:|
| 공통 거래행 수(동일 서명 반복 횟수 포함) | 5,304 |
| CSV에만 남는 행 | 0 |
| API에만 남는 행 | 0 |
| 서로 다른 비교 서명 | 5,190 |
| 반복 서명 묶음 | 71 |
| 반복 때문에 추가되는 행 | 114 |

시군구·법정동·단지명·지번·계약일·거래금액·정확한 전용면적·층·건축연도·주택유형·해제 여부/일자·거래유형을 비교했다. 금액은 만원 단위의 쉼표를 제거하고 면적은 `Decimal`로 비교하여 `59.9700`과 `59.97`의 표현 차이만 통일했다. 반올림·면적 구간화·유사 이름 매칭은 하지 않았다. 지번의 앞자리 0과 부번 `0000`/공백을 통일했으며, 이름은 바깥 공백만 제거했다. 해제일 `-`/공백은 해당 다운로드 시점의 해제 미표시, 거래유형 `-`/공백은 미상으로 처리했다.

양쪽 모두 해제표시 0행·산지번 0행이었다. 주소·단지명 차이 또는 설명이 필요한 잔여 불일치는 없었다. 동일 서명의 실제 복수 거래 가능성을 보존했으며 어떤 행도 임의 삭제하지 않았다. 원문 예시·월별 집계·소스 SHA-256·비교 서명은 [상세 JSON](estate_capital_csv_overlap.json)에 기록했다.

CSV 관측시각은 `2026-09-09T00:48:19.229159+00:00`, 기존 역사 원본 수집완료시각은 `2026-09-08T16:38:33.669901+00:00`이며 원본 Git 커밋은 `e1e48354f7cb2f15f2b4c045c7ce48569869688b`다. 이번 결과는 **광명 2006년의 현재 내려받은 회고 자료**에 한정된다. 2006년 공시 당시 빈티지 또는 다른 시도·연도의 완전성을 보증하지 않는다.

새 경기 CSV와 기존 광명 자료를 함께 붙이면 2006년만 5,304행이 중복된다. 예정한 소유권대로 2006~2020년 기존 역사에서는 서울만 채택하고, 경기·인천은 새 CSV를 사용한다.
