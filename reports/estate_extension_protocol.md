# 2026-09-08 추가 데이터 실험의 사전 기준

모델 결과를 확인하기 전에 작성했다. 이미 앞선 가격·잠재력 실험에서 2024~2026년 시장을 관찰했으므로 이번 결과를 처음 공개된 맹검 시험이라고 부르지 않는다. 새 입력 정보를 고정한 추가 검증이다.

- 현재 가격: 기존 월간 모델과 같은 거래·층·기존 학습 설정으로 기준 모델, KB 아파트 매매·전세 지수 추가, 신규 전세 추가, 두 종류 추가를 비교한다. 지수는 수준이 아닌 1/3/6/12개월 로그 변화다. 서울은 자치구, 경기는 광명시 외 시도, 인천은 행정구역 변경 영향을 피하기 위해 시도 지수로 맞춘다.
- 확장 학습: 2023년으로 2024년, 2024년까지로 2025년, 2025년까지로 2026년을 평가한다. 2026년은 3~7월까지로 고정한다. 파라미터를 평가 결과에 맞춰 반복 조정하지 않는다.
- 신규 전세: 동일 단지명·지번·전용면적의 순수 전세만 연결한다. 신규·갱신·미상은 별도 집계하며 신규 3개 이상의 서로 다른 공개 행 서명이 있어야 대표가격을 계산한다. 반복 서명 유지 민감도도 확인한다. 공개 행 서명은 확인된 고유 거래 ID가 아니다.
- 지연: 기준 지수는 판단월보다 두 달 앞선 월까지, 전세는 계약일+31일 및 접수연도 조건을 쓴다. 이는 가정 실험이며, 현재 내려받은 개정 지수와 전세 파일을 당시 공표본으로 주장하지 않는다. 전세 연도별 파일 수정일을 사용하는 보수적 비교와 KB 3개월 지연을 추가한다.
- 가격 갱신 주기: 동일 대상·층으로 월별 갱신과 3/6개월 동결을 비교한다. 동결 주기와 과거 거래 집계 창, 미래 성과 측정 기간은 구분한다.
- 가격 모델 승격: 2025년과 2026년의 MAE 각각 3% 이상 개선, 지역별 MAE 악화 2% 이내, 단지 묶음 부트스트랩 개선의 95% 구간 하한이 0 초과여야 한다. 현재 운영에도 같은 입력 자료가 유효한 시점으로 공급돼야 한다. 후보가 이 기준을 통과하지 않으면 계수는 유지하고 검증 결과를 공개한다.
- 잠재력: 2016~2020년 매매를 서울 25개 구와 광명시에 한정해 추가한다. 90/180일 진입 대표가격, 6~12개월·18~24개월 결과를 비교한다. 판단은 반기별로 하며 완전히 성숙한 라벨만 과거 학습에 넣는다. 두 지명 성공 사례는 학습에서 제외한다. 가격 입력만 사용한 모델과 전세·지수 추가 모델을 같은 후보군에서 비교하고, 상위 10%를 결과 관측 여부와 관계없이 먼저 선정한다.
- 잠재력은 여러 시점의 상대 성과·전체 후보 대비 차이·미관측 비율·거래비용 민감도를 함께 공개한다. 작은 평균 개선이나 성공 사례 재현만으로 투자 점수로 승격하지 않는다. 구조적 사업 정보와 실제 매수 가능 호가를 추가하지 못한 경우 이를 남은 한계로 기록한다.

원본 공개 경로: [서울 전월세 파일](https://data.seoul.go.kr/dataList/OA-21276/A/1/datasetView.do), [KB 통계 다운로드](https://kbland.kr/pages/kbStatistics.html). KB 지역 지수는 개별 단지 KB시세가 아니다. KB 평균·중위가격 및 전세가비율에는 표본 개편 영향이 있어 지수 변화와 혼용하지 않는다.
