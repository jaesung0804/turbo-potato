## 추가한 후보와 비교

한 가지 고정된 v4 설계를 기존 v3와 같은 전체 평형·연도에 비교했다. 각 시험 연도의 혼합 비중은 이전 연도에서 결정하며 비중 선택과 오차 구간 보정 단지는 분리한다. 과거 연도에서 반복 실험한 연구 결과로 취급하며, 새로운 전향적 검증이라고 부르지 않는다.

| 시험 연도 | 평형 수 | v3 MAE | v4 MAE | 변화 | v4 구간 포함률 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2023 | 28,753 | 548.88 | 502.31 | -8.48% | 77.40% |
| 2024 | 33,380 | 366.76 | 330.98 | -9.76% | 93.14% |
| 2025 | 36,277 | 414.98 | 385.02 | -7.22% | 81.16% |
| 평형 수 가중 합산 | 98,410 | 437.75 | 400.96 | -8.40% | — |

단위는 만원/평이다. 지역·전년 이력·소표본별 상세 수치와 실행 라이브러리 버전은 [비교 JSON](estate_model_comparison.json)에 있다. 모든 지역·시험 연도의 MAE가 감소했지만 일부 집단의 구간 포함률은 80% 미만이다. 특히 2023년 전년 이력 보유 집단 67.35%, 2025년 전년 이력 부재 집단 75.66%를 숨기지 않는다.

v4는 최대 3년 전의 동일 평형 이력을 보완하고, 이력이 없으면 유사 면적의 충분한 표본을 갖춘 동→구→시도 가격을 사용한다. 이 비교 기준에서의 로그 가격 차이를 LightGBM으로 학습한다. 월 모델은 버전별로 따로 저장한다. 모델 파일 크기는 약 180KiB로, 브라우저에는 모델을 보내지 않는다.

## 검증 및 적용 범위

원본 상태의 5,727개 파티션과 CSV 해시, 기존 월 모델의 해시를 확인했다. 기존 모델로 만든 로컬 사이트는 모든 연도·전체 기간의 거래수와 평형수를 유지했으며 실제 데이터 디코딩·검색·순위 검사를 통과했다.

모델 코드에는 현재·미래 가격 변조 시 과거 입력 불변, 입력 순서 불변, 이력 유효기간, 보정 표본의 단지 분리, v3/v4 월 모델의 파일 보존, 한국어·줄바꿈 검증을 추가했다. 사용법 페이지에는 전체 비교와 집단별 오차·포함률을 추가했다.

Python 테스트 41개, 전체 조회 UI 검사, 기존/후보 사용법 페이지 렌더링 검사를 통과했다. v4도 2026년의 비교 대상 33,242개를 전부 생성했고 기존 v3 모델 파일의 SHA-256은 보존됐다. 브라우저 자동화 연결은 이 세션에서 초기화되지 않아 시각적 화면 검사는 수행하지 못했으며, JavaScript 실행·HTML 요소 연결·실제 전체 데이터 디코딩으로 검증했다.

이번 변경의 운영 기본값은 v3다. v4는 명시적으로 선택해 학습·추론·로컬 사이트를 생성할 수 있다. 이 점검과 로컬 검증 자체는 GitHub 배포를 변경하지 않았다.
