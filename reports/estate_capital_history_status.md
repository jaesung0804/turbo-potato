# 수도권 장기 매매·전월세 확장 최신 현황

**경기 2009년 매매 140,861행을 추가 확보하여 현재 5/81개·755,674행, 잔여 76개다.** 원본과 체크포인트는 [현재 저장 커밋](https://github.com/jaesung0804/turbo-potato/tree/de8bd939eed594efd9bad670cf47aee737978d71)에 보존했다. 직전 실행은 세 차례 재시도가 아니라 재시도 밖에 있던 초기화 단계에서 실패했다. 오류 진단과 초기화 재시도를 수정했으며 [진단·복구 보고서](estate_capital_csv_diagnosis.md)에 근거와 100개 테스트 결과를 기록했다. 기존 정규화 저장본은 4개 자료 기준이며 신규 2009 원본의 학습·백테스트·홈페이지 반영은 아직 하지 않았다.

아래는 최초 4개 자료 확보 당시의 기록이다. 최신 집계는 위 내용과 [상태 JSON](estate_capital_history_status.json)을 따른다.

## 최초 4개 자료 확보 기록 — 2026-09-09

**전체 수집은 미완료다. 수집기·복원·정규화 구현과 확보분 검증은 완료했고, 새로운 모델 백테스트와 홈페이지 반영은 아직 실행하지 않았다.** 상세 수치와 실행 기록은 [상태 JSON](estate_capital_history_status.json)에 보존한다.

공식 제공 범위는 서울·경기·인천 모두 매매 2006-01부터, 전월세 2011-01부터다. 전월세 2006~2010은 미제공 구간이다. 2026-09는 수집일인 9월 9일까지의 부분월이며, 이후 신고·정정으로 과거 행도 바뀔 수 있다. 출처: [국토부 공개 안내](https://rt.molit.go.kr/pt/info/info.do), [시도별 CSV 자료제공](https://rt.molit.go.kr/pt/xls/xls.do?mobileAt=).

| 이번에 실제 확보·검증한 출처 | 원본 행 수 | 순수 전세 조건 행 수 |
|---|---:|---:|
| 경기 매매 2006 | 206,224 | — |
| 경기 매매 2007 | 117,164 | — |
| 경기 매매 2008 | 110,054 | — |
| 경기 전월세 2011 | 181,371 | 139,547 |
| 합계 | **614,813** | **139,547** |

순수 전세는 아파트·월세 0·양의 보증금으로 분리한다. 나머지 41,824행은 월세 조건이다. 거래 구분 원문과 금액 조건이 어긋난 13행도 원본에 남긴다. 동일 조건의 복수 거래와 해제 표시를 보존했으므로 이 수치는 임의 중복 제거를 거친 계약 수가 아니다.

원본은 [별도 수집 상태](https://github.com/jaesung0804/turbo-potato/tree/1747755718e829d8f581f88854337702eb284072)에 Git 지문·수집 시각·조회 조건·기간별 건수와 함께 보존했다. 이 스냅샷의 전체 상태는 계속 `failed`, 계획 81개 중 완료 4개·잔여 77개다. 최초 로컬 전월세 시험 파일도 재다운로드 없이 검증하여 포함했다. 저장 상태 복원 시 각 파일의 바이트 수와 SHA-256을 검사한다.

확보분의 [정규화 저장본](https://github.com/jaesung0804/turbo-potato/tree/88334f16ed1c2a6cc22ad365d9f426306de90fb6)은 원문 보존형 614,813행과 매매 모델 입력 형식 432,222행을 포함한다. 지번 필드가 서로 맞지 않는 매매 1,220행은 원문에 보존하고 모델 입력에서 제외했다. 압축 파일 16개·72,867,780바이트에 행 수와 SHA-256을 기록했으며, 부분 범위임을 `full_requested_scope_complete: false`로 명시했다. 원격 커밋을 새 작업 경로에 복원한 뒤 16개 파일의 바이트 수·SHA-256·압축 해제 행 수와 부분 출처 manifest 지문이 모두 일치함을 확인했다. 기존 API 자료와의 전체 병합은 아직 하지 않았다.

첫 [전체 수집 실행](https://github.com/jaesung0804/turbo-potato/actions/runs/34297326558)은 경기 2006·2007을 완료한 뒤 2008 건수 조회 연결이 끊겼다. 완료 파일을 재사용한 [두 번째 실행](https://github.com/jaesung0804/turbo-potato/actions/runs/34298091259)은 2008을 추가 확보했지만, 2009 다운로드에서 CSV가 아닌 응답을 받아 중단했다. 2009 조회 건수는 140,861이었으며, **이 행들은 확보했다고 세지 않는다.** 응답 본문을 보관하지 않아 서버 오류·접근 제한 중 어느 쪽인지는 확정하지 못한다. 같은 다운로드를 반복하거나 실행 위치를 바꿔 다시 요청하지 않았다.

기존 매매 수집과 같은 프로젝트 인증 설정으로 [공식 매매·전월세 API를 각각 한 번 확인](https://github.com/jaesung0804/turbo-potato/actions/runs/34298847695)했으나 두 요청 모두 45초 후 시간 초과였다. HTTP/API 오류 코드를 받지 못했으므로 전월세 활용신청이 거절됐다고 단정할 수 없다. 기존 매매 API의 과거 성공 기록은 유효하다. 코드 수정만으로 요청이 자동 재개되지 않도록 두 워크플로는 수동 실행으로 남겼다.

기존 보유 매매는 서울·광명 2006~2020 원본 1,217,848행과 수도권 2021~2026-09 원본 1,145,460행이다. 이번 CSV와 겹치는 광명 기록을 단순 합산하면 중복된다. [광명 2006 전수 비교](estate_capital_csv_overlap.md)에서 CSV·API 각 5,304행의 내용과 반복 횟수가 모두 일치했으며 양쪽만 남는 행은 0이었다. 전체 수집 후에는 서울 과거 매매·경기/인천 과거 매매·최근 수도권 매매의 기간별 사용 출처를 고정한다. 아직 채워지지 않은 구간을 현재 정상 입력에서 지우거나 새 모델에 끼워 넣지 않았다.

전세 기존 자료는 서울의 2016~2025 **접수연도 파일**이며, 이를 수도권 전체의 계약연도별 전세를 이미 확보한 것으로 해석하지 않는다. 이번 경기 2011 전월세는 별도 확보분이다.

후속 검증은 [확장 검증 기준](estate_capital_expansion_protocol.md)에 기록했다. 기존 서울·광명에서 고정한 사양과 새 경기·인천 지역을 구분하고, 현재 가격 오차와 향후 상대 수익률을 따로 평가한다. 전세 변수 추가 효과는 같은 후보·판단일·목표 기간의 공통 표본에서 비교한다. 현재 다운로드는 과거 공시 당시 빈티지가 아니므로 신고 시차 가정과 진짜 최초 관측 시각을 구분한다. 자료 확대만으로 모델 개선이나 5년 예측 검증 완료를 주장하지 않는다.
