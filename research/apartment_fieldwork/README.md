## 근거 규칙

- `kind`는 공식자료, 플랫폼 표시, 보도 인용, 후기, 광고, 추론, 미확인 중 구분한다. `confidence`는 주장별 A~D이며 단지 전체의 신뢰등급이 아니다. A는 확인한 공공 원자료·직접측정, B는 열람한 플랫폼/언론 원문의 명시적 정보, C는 후기·광고·파생자료·검증되지 않은 해석, D는 미확인·해결되지 않은 상충이다.
- 가격 예측의 신뢰등급과 이 기록의 근거 A~D는 별도 정보다. 같은 점수로 합치거나 한쪽 등급으로 다른 쪽을 채우지 않는다.
- `published_at`은 출처의 공개일, `observed_at`은 실제 현상·거래의 시점, `collected_at`은 수집일이다. 알려진 정밀도까지만 쓰며 모르는 시점은 `null`로 둔다. 현재 확인한 시설값을 과거 시점에 소급하지 않는다.
- `scope`에 단지·동·라인·층·향·정확한 전용면적을 남긴다. 정수 평형을 정확한 전용면적으로 임의 변환하지 않는다. 동/층/향이 모르는 후기를 전체 단지의 특성으로 일반화하지 않는다. 공식 식별자나 원장 주소 연결이 안 된 경우 식별 확인대기로 남긴다.
- 알려진 부재는 `false`, 미확인은 `null`이다. 주차장 존재와 승강기 직결, 한강뷰·하천뷰·호수뷰·개방조망은 별도 주장으로 저장한다.
- 가격은 `asking`, `transaction`, `reported_market_price`, `KB_estimate`를 구분한다. 실거래를 인용한 보도도 정부 거래 원장 직접 검증과 구분한다. 최고가/분양가의 차이를 반복매매 순수익률로 부르지 않는다.
- 지도 서비스의 기준점 거리는 문 앞 출근시간이 아니다. 실제 출입구·도착지·노선·환승·대기·측정시점을 확인해야 한다. 예정 노선을 현재 운영 노선에 섞지 않는다. 토지의 평지 표시는 역까지 경로 전체의 경사를 뜻하지 않는다.
- 외부 사진은 출처 링크와 대상·촬영시점·권리 확인 상태를 남긴다. 사진 캡션이 다른 단지를 가리키거나 촬영대상이 확인되지 않으면 단지 사진으로 확정하지 않는다. 내부 사진은 특정 세대의 범위를 넘겨 일반화하지 않는다.
- 모든 초기 기록의 `model_eligible`은 `false`다. 식별 연결, 시간 누수, 원출처, 표본 편향, 적용범위와 상충을 검토한 뒤 별도 승인·검증 절차가 필요하다. 이 자료는 모델 가중치·학습·배포를 변경하지 않는다.

## 저장과 비용

공개 출처에 기반한 요약과 메타데이터만 조사 전용 브랜치에 작게 저장한다. 개인 운영조건·비공개 대시보드 주소·계정 정보·인증키는 포함하지 않는다. 외부 원본 이미지와 대형 파일은 자동 다운로드하지 않는다.

2026-09-10 확인한 기존 workflow는 이 조사 브랜치의 push에 해당하지 않는다. 모든 PR에 전체 검증을 수행하는 기존 workflow가 있으므로 현재는 PR을 만들지 않는다. main, 기존 수집 스케줄, 배포, 모델 코드와 workflow는 수정하지 않는다. 새 Actions·외부 유료 API·호스팅·구독·결제·정기 자동화는 이 연구 기록에 추가하지 않는다. 계정 전체의 과금 설정을 변경했다는 의미는 아니다.
