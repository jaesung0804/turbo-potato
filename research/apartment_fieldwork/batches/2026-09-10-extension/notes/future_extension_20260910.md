# 개별 광고 비교와 모델·조사 양식 개선 — 2026-09-10 추가 조사

작성: 서진 / 미래연구실장 / 역할 ID FUTURE. 공개 연구 기록. 상태: 1차 비교 작성, 추가 근거 검수 중.

비교 단위는 단지명만이 아니라 **광고 ID + 관찰시점 + 정확한 전용·공급 타입**이다. 아래는 광고에 표시된 주택을 조사하기 위한 비교이며, 현재 매수 가능한 물건의 확정 목록이나 개인별 순위가 아니다. 실제 가용성 확인시각은 모두 `null`이다. 원래 조사 보고서와 계산 결과는 변경하지 않았다.

## 5. 데이터 양식과 연결 규칙 개선

| 필드 묶음 | 저장할 값 | 방지하려는 오류 |

`advertiser_confirmed_at`이 플랫폼에 표시된 날짜이면 정밀도를 `date`로 둔다. 조사자가 중개사에게 직접 확인한 시각과 분리한다. 원문·수치·단위를 보존한 뒤 필요한 경우에만 파생값을 만든다. 금융·정책 자료에는 관측기간뿐 아니라 발표시점과 수정 차수도 함께 둬 당시 알 수 없었던 수정값의 유입을 막는다.

연결에는 다음 세 경계를 둔다. 같은 광고의 새 관찰은 새 버전이고, 같은 주택의 광고 중복은 별도 연결이며, 같은 타입의 여러 주택은 하나의 세대로 합치지 않는다. 주택형 면적은 원문 정밀도를 문자열로 보존한 뒤 수치 연산용 값을 파생한다. 표시 반올림을 허용한 연결은 주소·타입·거래서명 등 추가 근거와 연결 사유를 남긴다. 모델의 단지·정확 전용면적 키가 일치해도 개별 세대·공급타입·실제 층까지 일치했다는 뜻으로 바꾸지 않는다.

광고와 실거래의 동·층·면적·기간이 겹쳐도 동일 세대의 계약으로 자동 확정하지 않는다. `same_type_trade_observed`와 `same_unit_sale_confirmed`를 구분하고, 동일 물건의 계약 연결 근거가 없으면 `asking_to_sale_discount=null`로 둔다. 이 경우에는 관찰 호가와 동일 타입 체결 분포를 각각 비교한다. 검색 목록에서 광고가 보이지 않거나 원문이 사라진 사실도 거래 완료와 구분해 기록한다.

입력의 `claim_kind`는 `observed_platform_fact`, `advertiser_claim`, `image_observation`, `research_inference`, `unknown`으로 나누고 출처 신뢰등급과 별도로 둔다. 같은 원거래를 재전달하는 플랫폼 둘은 `independence_group_id`를 공유한다. 사진을 여러 번 판독해도 독립된 촬영·현장 확인이 늘어난 것으로 세지 않는다. 사진에서 샤워 설비가 보이는 사실과 실제 작동·배수·동시 사용 가능성은 다른 항목이다.

가격 비교의 총비용 범위도 분리한다. 이 표는 광고 매매가만 비교하며 취득 부대비용, 실제 수리 견적, 금융비용, 입주 전 주거 공백 비용을 합산한 표가 아니다. 그러한 값이 확보되면 금액·기준일·견적 또는 제도 출처를 따로 연결하고, 근거 없는 정액 수리비나 층 할인율로 보완하지 않는다.

개선 순서는 다음과 같다. 먼저 광고·거래·시세 종류와 정확 타입·시간·단위를 분리하고, 광고 관찰을 실제 가용성으로 승격하는 표시를 없앤다. 다음으로 개별 동·층·사진·이동 경로의 연결과 누락 사유를 보강한다. 이 자료가 쌓이면 공급타입·수리·무단차·실제 통근의 추가 설명력을 별도 검증하되, 시간 순서를 지킨 검증자료에서 개선 여부를 확인한다. 이번에는 생산 모델의 피처나 학습을 변경하지 않았다.

예를 들어 현재 추출에서 `price_billion=9.0061`은 문서상9.0061억원이다. 원화로 옮길 때는 단위 근거를 보존하고 `9.0061 × 100,000,000 = 900,610,000원`으로 변환한다. 필드명만 보고10억 단위로 읽는 오류를 막기 위해 새 스키마는 `*_krw` 또는 명시적인 `*_oku`를 사용한다.

## 6. 조사 도구 표시 수정

기존 도구에서 광고 확인 플래그가 있으면 `provisional=false`가 되는 문제를 별도 [ranking_engine_v2.py](../../../tools/ranking_engine_v2.py)에서 수정했다. v2는 모든 결과를 `exploratory`, `provisional=true`로 표시하고 광고 관찰·가용성·점유 근거를 별도 메타데이터로 전달한다. 기존 게이트와 수치 계산은 보존했다. [변경 내용과 확인 결과](ranking_engine_v2_changes.md)

이 문서에서 새 개인 입력·점수·순위를 만들지 않았다. 결측을 0이나 평균으로 채우지 않으며 현재 표시 도구는 조사 보조용이다.

## 7. 거시·정책을 가격 해석에 연결할 때

한국은행은 2026-08-27 기준금리를2.75%에서3.00%로 올렸다. 금융위원회는8/13 발표에서 연간 가계부채 총량 증가율을 당초1.5%에서3% 수준으로 관리할 계획을 설명했다. 금리와 대출총량은 서로 다른 변수이며 후자는 모든 개인의 대출한도 확대를 뜻하지 않는다. [한국은행 결정 원문](https://www.bok.or.kr/portal/bbs/P0000559/view.do?nttId=11064191&menuNo=200690&programType=newsData&relate=Y&depth=200690), [금융위원회8/13 원문](https://www.fsc.go.kr/no010101/87517)

이번 F50의 입력 마감일8/1은 위8/13·8/27 발표보다 앞선다. 해당 발표를 이 모델의 관측 입력이 직접 반영했다고 가정하지 않는다. 광고와 기준가의 차이에는 주택 상태뿐 아니라 입력 마감 이후의 시장·금융조건 변화도 섞일 수 있다. 현재가격 모델 원값을 거시 뉴스로 임의 수정하지 않고, 다음 시점 재관찰 때 변화 원인을 분리해 검토한다.
