# 조사용 비교 도구 v2 변경 기록

작성: 서진 / 미래연구실장 / FUTURE. 2026-09-10.

기존 도구는 `current_listing_verified=true`이면 순위 행의 `provisional`을 `false`로 표시했다. 광고 원문을 확인한 사실만으로 실제 거래 가능성이나 매수 판단이 확정된 것처럼 읽힐 수 있어 별도 파일 [ranking_engine_v2.py](../../../tools/ranking_engine_v2.py)를 만들었다. 원본과 기존 저장 결과는 변경하지 않았다.

변경은 표시와 메타데이터에 한정한다.

- 전체 결과와 개별 순위·보류 행은 항상 `analysis_status="exploratory"`, `provisional=true`다.
- 광고 관찰시각, 광고 확인일, 실제 가용성 확인시각, 점유 주장과 출처를 `listing_metadata`로 따로 전달한다. 값이 없으면 `null`이며 다른 플래그에서 추정하지 않는다.
- `advertiser_confirmed_at`에 플랫폼이 표시한 광고 확인일을 넣는다면 날짜 정밀도와 플랫폼 출처를 함께 보존해야 한다. 조사자가 중개사에게 직접 확인했다는 뜻으로 바꾸지 않는다.
- 기존 `current_listing_verified`와 `constraints` 게이트는 호환성을 위해 그대로 둔다. 기존 이름은 광고 관찰 여부에 관한 레거시 입력이며 실제 매물 가용성을 검증하는 게이트가 아니다.
- 점수 계산, 5개 혼합 비중, 필터, 동점 처리, 기여도, 민감도, 결측 처리와 가정 범위 계산은 동일하다. 출력 스키마 버전만 2로 올렸다.

광고 확인 플래그가 true/false인 두 경우를 엄격 게이트 사용/미사용 각각에서 확인했다. 모든 출력 행이 탐색 상태를 유지했고 기존 통과·보류 결과가 보존됐다. 기존 저장 입력으로 5개 비중의 수치·순서와 민감도 출력을 메모리에서 비교해 메타데이터 이외 결과가 같음을 확인했다. 검사 과정에서 원본 입력이나 저장된 순위 파일을 덮어쓰지 않았다.

이 변경은 실제 매물의 존속·권리·입주 가능성·재무 적합성을 검증하지 않는다. 생산 가격 모델, 수집기, 학습 및 배포와 독립된 오프라인 조사 도구의 표시 수정이다.
