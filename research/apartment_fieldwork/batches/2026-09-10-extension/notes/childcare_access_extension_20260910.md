조회일: 2026-09-10. 기존 동결본을 수정하지 않는 별도 추가 기록이다. 단지·시설의 공개 정보만 사용하며 개인 직장·가족·거주 정보는 포함하지 않는다. 현장 방문, 시설 연락, 입소 신청 또는 진료 예약을 수행한 기록이 아니다.

## 2. 직접 확인한 어린이집 공식 근거

### C01. 시립루나리움어린이집

- 공식 시설 코드: `41450000342`. 국공립, 개원일 2020-02-17, 주소는 하남시 아리수로 499 관리동 어린이집으로 게시된다. 평일 운영시간 안내는 07:30~19:30, 통학차량 미운영이다. [어린이집정보공개포털 요약](https://info.childcare.go.kr/info/pnis/search/preview/SummaryInfoSlPu.jsp?STCODE_POP=41450000342&flag=YJ)
- 조회 시 만 0세 0반, 만 1세 2반, 만 2세 4반을 공시한다. 총정원 60명·총현원 55명이라는 표기는 **빈자리 5명 또는 즉시 입소 가능**이라는 뜻이 아니다. 해당 페이지도 총정원과 연령별 정원 합의 차이를 설명한다. [영유아 및 교직원 공시](https://info.childcare.go.kr/info/pnis/search/preview/ChildStaffSlPu.jsp?STCODE_POP=41450000342&flag=BG)
- 건물은 전용·총 1층으로 게시된다. 문턱, 출입문 폭, 경사로 기울기, 유모차 보관·회전 공간은 공시에서 확인하지 못했다. [기본현황](https://info.childcare.go.kr/info/pnis/search/preview/BasisPresentConditionSlPu.jsp?STCODE_POP=41450000342&flag=GH)

### C02. 루나리움어린이집

- 공식 시설 코드: `41450000297`. 가정 어린이집, 개원일 2018-04-06, 아리수로 499에 소재한다. 공개 노트에는 주거동 세대번호·대표자 개인정보를 옮기지 않는다.
- 조회 시 만 0세 2반·만 1세 1반·만 2세 1반, 아동수는 각 6·5·4명으로 공시한다. 평일 운영시간 안내 07:30~19:30, 통학차량 미운영이다. **반 편성 확인은 신규 원아 입소 승인이나 대기기간 확인과 다르다.** [공식 요약](https://info.childcare.go.kr/info/pnis/search/preview/SummaryInfoSlPu.jsp?STCODE_POP=41450000297&flag=YJ)

두 기관은 단지명만으로 합치지 않고 시설 코드로 구별해야 한다. 가정 어린이집의 0세반을 국공립 어린이집의 0세반으로 옮겨 기록하면 잘못된 비교가 된다. 반 연령은 해당 연도 공시의 출생연도 정의를 따르며 생일 경과 여부만으로 임의 재분류하지 않는다.

### C03. 지샘병원 — 군포시 의료기관 후보

- 병원 공식 홈페이지에서 군포시 군포로 591 주소와 소아청소년과, 응급의료센터 안내를 확인했다. 메인 안내는 응급실 24시간·응급의학과 전문의 진료를 명시한다. 이는 **영유아 모든 질환을 언제든 수용한다는 확인이 아니다**. [병원 공식 안내](https://www.gsamhospital.com/)
- 소아청소년과 페이지에 신생아부터 소아청소년을 진료 대상으로 안내하고 2026-09-07~12 주간 진료표를 게시한다. 당일 접수·휴진 변동·응급 수용 가능 여부와 하이어스 출입구부터의 이동시간은 확인하지 않았다. [소아청소년과 공식 안내](https://www.gsamhospital.com/bbs/content.php?co_id=pedmedical)
- 상충 표시: 같은 소아청소년과 페이지의 본문 위치 설명은 지샘병원 2층인데, 아래 위치안내도 텍스트에는 안양샘병원 별관이라는 다른 병원명이 나타난다. 해당 하단 배치도를 군포 지샘병원의 유모차 동선 근거로 사용하지 않는다. 진료 품질·접종·검진 상품을 추천하거나 신청하지 않았다.

## 3. 거리·접근성·운영 상태의 누락 처리

| 필드 | 이번 확인값 또는 처리 |
|---|---|
| `captured_at` | 2026-09-10 |
| `source_updated_at` | 공식 공시 본문에 최종수정일이 명확히 표시되지 않아 `null` |
| `observed_operation_status` | 공시 게시·반 편성 확인. 당일 개원·휴폐원 상태 확인은 `null` |
| `vacancy`, `admission_possible`, `wait_days` | 모두 `null`; 정원에서 현원을 빼서 채우지 않음 |
| `distance_origin` | 세대 현관·동 현관·단지 출입구 중 확정된 공통 기준점 없음 |
| `distance_destination` | 시설 출입구를 직접 확인하지 못함 |
| `walk_distance_m`, `walk_minutes`, `stroller_route_minutes` | 모두 `null`; 동일 도로명 주소를 0m로 환산하지 않음 |
| `pediatric_clinic_open_now`, `infant_emergency_acceptance` | 실시간 운영·수용 상태 미확인. 종합병원 또는 응급실 존재만으로 채우지 않음 |
| `step_free_chain_verified` | 세 단지 모두 `null`; 구간별 근거가 모일 때만 전체 연결 판정 |

진료기관은 일반 소아청소년과 외래, 야간·휴일 진료, 응급의료기관, 영유아 응급 수용 가능 상태를 각각 구분해야 한다. 기관 유형이나 거리를 의료의 질·접종 추천으로 바꾸지 않는다. 시설 운영표와 길찾기 결과를 확보하더라도 출발 동·출입구·요일·시간과 관찰일을 함께 남긴다.

## 4. 양식 개선 제안 — 욕실 수와 사용 기능 분리

욕실 2개라는 평면 표기를 샤워 가능한 공간 2개로 간주하지 않는다. 향후 양식에는 `bathroom_count`, `shower_capable_space_count`, `bathtub_count`, `wet_or_dry_zone`, `toilet_and_basin_only`, `actual_renovation_status`, `photo_taken_at`, `source_scope`를 분리한다. 공용 평면도·3D 이미지·시공 사진·현재 매물 사진의 표시가 다르면 각각의 자료 범위와 상충 내용을 남긴다. 도면에 욕조가 보이거나 안방 욕실에 변기·세면대만 표시된 관찰은 실제 세대의 샤워 설비·배수·수리 상태 확인을 대체하지 않는다. 기존 동결된 상세 임장 양식에는 이번 검수에서 변경을 가하지 않았다.
